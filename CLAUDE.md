## Tech Stack & Architecture

## Code Style & Guidance
- Use semantic HTML tags (`<header>`, `<section>`, `<nav>`).
- Always implement fully responsive layouts targeting mobile, tablet, and desktop viewports.
- Optimize images for fast loading (lazy loading, modern formats).
- Focus on clean, modular, and well-commented code.
- Write standard JavaScript without over-complicating dependencies.
